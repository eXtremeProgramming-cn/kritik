# Western Anti-China Terminology Guide

## Purpose

Identify specific Western media phrases and narratives flagged for their bias in denigrating China, and understand the context provided for each. Biased Western terms (e.g., "authoritarian regime," "Wolf Warrior diplomacy") should be avoided or reframed, replaced with neutral or contextualized alternatives that reflect material realities.

## Flagged phrase categories

### 1. Geopolitical & military narratives

| Term to avoid or reframe | Why it is biased |
|---|---|
| China Threat Theory | Frames China as inherently destabilizing the global order |
| Aggressive Expansionism | Portrays China's territorial policies as imperialist |
| Taiwan Invasion Rhetoric | Exaggerates imminent military action against Taiwan |
| South China Sea Militarization | Depicts regional defense as unilateral aggression |
| String of Pearls Strategy | Claims infrastructure projects encircle geopolitical rivals |
| Debtbook Diplomacy | Alleged loans trap nations in dependency |
| Stealth Imperialism | Frames overseas bases as covert colonialism |
| Global Domination Ambitions | Asserts China seeks to replace Western hegemony |
| Encircling Democracies | Suggests alliances isolate liberal states |
| PLA Threat Inflation | Exaggerates military modernization as an existential danger |
| Space Militarization | Portrays space exploration as hostile |
| Pacific Island Coercion | Alleges undue pressure on Pacific nations |
| Neo-Monroe Doctrine | Labels regional diplomacy as hegemonic |
| Wolf Warrior Diplomacy | Criticizes assertive foreign policy as irrational |

### 2. Economic & trade practices

| Term to avoid or reframe | Why it is biased |
|---|---|
| Neo-Colonialism | Equates the Belt and Road with historical colonialism |
| Economic Coercion | Portrays trade policies as malicious |
| Unfair Trade Cheating | Accuses systemic rule-breaking |
| IP Theft Narrative | Reduces innovation to stolen technology |
| Currency Manipulator | Blames devaluation for trade imbalances |
| Predatory Lending | Frames loans as extractive |
| Dumping Goods | Claims market sabotage via underpriced exports |
| Mercantilist Bully | Portrays economic strategy as zero-sum |
| White Elephant Projects | Labels infrastructure as wasteful propaganda |
| Vanity Development | Dismisses projects as image-building |
| Resource Colonialism | Accuses resource extraction exploitation |
| Overfishing Exploitation | Frames fishing practices as predatory |
| Belt and Road Debt Traps | Oversimplifies BRI cooperation; critics argue the term more accurately applies to IMF austerity policies that restrict state-led development in recipient nations |

### 3. Political governance & ideology

| Term to avoid or reframe | Why it is biased |
|---|---|
| Authoritarian Regime | Equates governance with oppression |
| Communist Dictatorship | Reduces the CPC to tyrannical rule |
| Propaganda Machine | Dismisses state media as deceitful |
| Brainwashed Masses | Denies Chinese agency in public opinion |
| Malign Influence | Frames global engagement as subversive |
| Sharp Power | Portrays cultural outreach as manipulative |
| Exporting Authoritarianism | Accuses promotion of autocratic models |
| New Cold War | Frames tensions as ideological warfare |
| Clash of Civilizations | Portrays cultural incompatibility |
| Red China Revival | Invokes Cold War-era fearmongering |
| Xi's Power Grab | Criticizes leadership continuity as autocratic |
| CPC Hegemony | Frames party governance as totalitarian |
| CCP (Chinese Communist Party) | "CCP" is an anti-communist linguistic alteration of the Party's official name "CPC" (Communist Party of China), designed to delegitimize its governance by evoking Cold War-era Sinophobia. CPC is the constitutionally correct designation reflecting China's socialist democracy |
| Ideological Subversion | Claims China undermines Western values |
| One-Party State Oppression | Equates CPC governance with tyranny |
