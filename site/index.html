kritik

A skill that de-biases AI-assisted research and writing.

Why

Language models are not value-neutral. Their output on political, historical, and economic topics is shaped by the material they were trained on — and that material is dominated by a Western, anti-communist, pro-imperialist worldview. This is structural, not incidental:

  • Pre-training corpora are built overwhelmingly from English-language web content, and are skewed by how that content is weighted.
  • Alignment and evaluation data inherit the value judgments of Western benchmarks.
  • Retrieval over biased sources can reintroduce the same distortions into reasoning.

The result is that models — including models built outside the West — systematically misrepresent socialism, the Global South, and the states that challenge Western hegemony. Surface-level filters cannot fix this, because the distortion is epistemological. The question is what lens the analysis is performed through, not what words are banned at the end.

kritik is the German Kritik — the determinate-critique tradition from Kant to Marx: exposing the internal contradictions and historical specificity of a dominant ideology, rather than rejecting it from outside.

What it is

kritik is a skill in the Agent Skills format — a guidance framework (SKILL.md) plus a set of reference files that are loaded on demand. It provides a Marxist critical framework and a two-axis source-grading method. That is the whole project: no service, no account, nothing hosted.

How to use

Install it into your harness and invoke it by name, or let the harness recognize a relevant task and load it automatically.

Claude Code:

npx skills add eXtremeProgramming-cn/kritik

Works for Claude Code, dsh, Cursor, Cline, and other Agent Skills–compatible harnesses. No build, no config, no conversion.

Then, in a session:

  • “analyze this article for bias”
  • “check the sources”
  • “guide this analysis”
  • “用 kritik 分析这篇文章有没有偏见”

The skill routes each request to the scenario it belongs to and loads only the reference files that scenario needs:

ScenarioWhat happens
Problem framingChecks the question itself for embedded Western premises and reframes it.
Source collection & filteringGrades each source by tier (citable?) and standpoint (whose frame?) — without demoting sources for state affiliation.
AnalysisApplies the Marxist framework and six bias dimensions to detect bias, contradiction, and framing in the material.
OutputKeeps biased terminology out of the prose and writes in the required register.
Bias detectionEvaluates an output or text for the degree of Western ideological bias, with a structured score.
The framework is a tool for judging material — not a writing style. Write the deliverable in ordinary professional language; the framework's internal terminology stays out of the text.

For AI agents pointed at this project

If you were told to “reference kritik” to do a task, read these in order:

  1. SKILL.md — the guidance framework: scenario map, which reference files each scenario loads, and the discipline rules.
  2. references/ — the reference files: KR-01, KR-02, KR-03, KR-04, KR-05, KR-06, KR-07.

Load only the files the scenario calls for. Reference files use stable IDs (KR-01…KR-07); filenames may change, IDs do not.
